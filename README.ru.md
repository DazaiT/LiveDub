# LiveDub

**Живой перевод и переозвучка речи для Windows.** LiveDub слушает всё, что играет на компьютере (звонок, стрим, видео на YouTube), распознаёт речь, переводит её и показывает субтитры поверх экрана. Перевод можно озвучивать голосом, а в обратную сторону программа умеет произносить *твои* слова в виртуальный микрофон, чтобы собеседник в звонке слышал тебя на своём языке.

## Возможности

- **Живые субтитры** поверх любых программ (игры в окне без рамки, браузеры, плееры). На экране остаются 3 последние фразы: новая крупная и яркая, старые мельче и тусклее, чтобы успеть дочитать.
- **Озвучка**: перевод речи собеседника звучит в твоих наушниках.
- **Голосовой режим**: зажимаешь клавишу, говоришь на своём языке, отпускаешь, и перевод звучит в виртуальный микрофон (Discord, Zoom, Teams, OBS, игры...). Пока клавиша зажата, твой настоящий голос не слышен собеседнику.
- **Полноценное окно с настройками**: светлая или тёмная тема по системе, интерфейс на русском, английском, нидерландском и украинском, выбор языков, размера модели Whisper, голосов, устройств звука и внешнего вида субтитров. Всё применяется сразу и сохраняется в `settings.json`.
- **Живёт в трее** и полностью управляется с NumPad. Субтитры можно переносить между мониторами.
- **Распознавание речи локальное** (Whisper через `faster-whisper`, на видеокарте NVIDIA или процессоре). В онлайн-сервисы уходят только короткие куски *текста* для перевода и озвучки.
- Любой язык, который знает Whisper (около 99), или `auto`, чтобы переводить всё, кроме твоего языка.

## Как это работает

```
 Всё, что ты слышишь (WASAPI loopback)
          |
   поиск фраз по громкости (пауза 0.5 с / максимум 6 с)
          |
   faster-whisper (локально) -> проверка языка
          |
   перевод: Google (gtx) -> deep-translator -> MyMemory
          |
          +--> субтитры (Tkinter, поверх всех окон, история из 3 строк)
          +--> edge-tts -> твои наушники                (озвучка, по желанию)

 Твой микрофон --> LiveDub --> VB-Cable --> "микрофон" в Discord/Zoom/OBS
   зажал Num7/Num8: микрофон для собеседника заглушен, речь записывается
   -> Whisper (твой язык) -> перевод -> edge-tts -> VB-Cable
```

Код разбит на несколько небольших модулей:

| Файл | Что делает |
|---|---|
| [`livedub.py`](livedub.py) | точка входа: логи, папка моделей, запуск всего |
| [`engine.py`](engine.py) | вся логика без интерфейса: звук, распознавание, перевод, голоса, клавиши |
| [`ui.py`](ui.py) | окно настроек (customtkinter), субтитры поверх экрана (Tkinter), значок в трее (`pystray`) |
| [`config.py`](config.py) | настройки по умолчанию, `settings.json`, списки языков и голосов |
| [`i18n.py`](i18n.py) | переводы интерфейса |
| [`updater.py`](updater.py) | скачивает языковые пакеты с GitHub, проверяет новую версию |
| `languages.json`, [`locales/`](locales) | дополнительные языки перевода и интерфейса (обычные файлы с данными) |

В `engine.py` работает несколько потоков, которые общаются через очереди:

| Поток / функция | Что делает |
|---|---|
| `capture_loop` / `record_session` | записывает звук системы, режет на фразы |
| `translate_loop` | Whisper, проверка языка, перевод |
| `dub_synth_loop`, `dub_play_loop` | готовит озвучку следующей фразы, пока играет предыдущая |
| `mic_loop` / `mic_session` | пересылает микрофон в виртуальный кабель, глушит его, пока держишь клавишу |
| `voice_out_loop` | твоя речь -> перевод -> голос в кабель |
| `hotkey_thread` | глобальные клавиши NumPad (`RegisterHotKey`), отслеживает отпускание клавиши |
| `model_worker` | загружает и перезагружает модель Whisper в фоне |

Tkinter трогает только главный поток: клавиши, трей и движок кладут команды и сообщения в очереди (`cmd_q`, `text_q`), а `ui.py` их обрабатывает.

## Что нужно

- Windows 10/11
- Python 3.10+ (в установщике поставь галочку **Add Python to PATH**)
- Интернет (перевод и озвучка онлайн)
- По желанию: видеокарта NVIDIA для быстрого распознавания
- Для голосового режима: [VB-Cable](https://vb-audio.com/Cable/) (бесплатный виртуальный аудиокабель)

## Установка и запуск

```
git clone https://github.com/DazaiT/livedub.git
cd livedub
pip install -r requirements.txt
python livedub.py
```

При первом запуске скачивается модель Whisper (около 1,5 ГБ для `medium`) в папку `models` рядом со скриптом. Для запуска без чёрного окна используй `start.bat`.

Откроется окно настроек, субтитры стартуют «спящими». Включи их переключателем в окне или клавишей **Num1** (NumLock включён). Если закрыть окно, программа продолжит работать в трее.

### Настройки

Открой вкладки **Языки**, **Звук**, **Субтитры**, **Модель** и **Приложение** в окне. Изменения применяются сразу и сохраняются в `settings.json` рядом с программой (удали файл, чтобы сбросить всё). Главное:

- **Языки**: на каком языке говорят другие (или автоопределение), твой язык и языки, на которые Num7 / Num8 переводят твою речь. Голоса выбираются тут же.
- **Модель**: `tiny`, `base`, `small`, `medium`, `large-v3`, на видеокарте или процессоре. Нажми *Применить* для перезагрузки. `small` легче для видеокарты в играх.
- **Приложение**: язык интерфейса, тема (как в системе / светлая / тёмная), запуск свёрнутым в трей, модификатор клавиш.

### Видеокарта NVIDIA

Скрипт сначала пробует видеокарту, а если не выходит, сам переходит на процессор. Если пишет про недостающие библиотеки, выполни `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`.

### Настройка голосового режима (один раз)

1. Установи VB-Cable и перезагрузи компьютер.
2. В программе для звонков (Discord, Zoom...) выбери микрофоном **CABLE Output**.
3. Настоящий микрофон оставь микрофоном по умолчанию в Windows (или выбери его на вкладке **Звук**).
4. Зажми **Num7** или **Num8**, говори, отпусти.

Голосовой режим включается вместе с программой, потому что приложение для звонков теперь слушает виртуальный кабель. Num6 выключает его.

## Управление (NumLock включён)

| Клавиша | Действие |
|---|---|
| Num1 | субтитры вкл / выкл (сон) |
| Num2 | субтитры на следующий монитор |
| Num3 | показать / скрыть оригинал |
| Num4 / Num5 | текст мельче / крупнее |
| Num6 | голосовой режим вкл / выкл |
| Num7 / Num8 (зажать) | говоришь -> перевод на язык, выбранный на вкладке **Языки** |
| Num0 | озвучка собеседника вкл / выкл |
| Num. | повторить последнюю фразу голосом |
| Num9 | выход |

Пока программа запущена, голые клавиши NumPad принадлежат ей. На вкладке **Приложение** можно переключить клавиши на Ctrl+Num (или Alt, или Ctrl+Alt). Субтитры можно перетаскивать мышью, правая кнопка очищает. То же самое есть в меню значка в трее.

## Добавление языков и обновления (без пересборки)

Языки - это обычные файлы с данными рядом с программой, их можно добавлять, не трогая код и не пересобирая `.exe`:

- **Новые языки перевода и голоса**: допиши запись в `languages.json`. Например: `"da": {"name": "Dansk", "voices": ["da-DK-JeppeNeural", "da-DK-ChristelNeural"], "mymemory": "danish"}`. Ключ - код языка Whisper, голоса - названия голосов [Edge TTS](https://github.com/rany2/edge-tts). Перезапусти программу.
- **Новые языки интерфейса**: скопируй `locales/_template.json` в `locales/xx.json` (`xx` - код языка), впиши `"name"`, переведи значения и перезапусти. Недостающие строки берутся из английского.
- **Скачать новые языковые пакеты** из этого репозитория: вкладка *Приложение* -> *Обновить языковые пакеты*. Скачиваются только маленькие JSON-файлы с данными, они проверяются, код программы не меняется.
- **Новая версия программы**: вкладка *Приложение* -> *Проверить новую версию* откроет страницу релизов. Обновление кода - это замена файлов (или повторный запуск `build.bat` для exe).

Pull request-ы с новыми `locales/*.json` и записями для `languages.json` приветствуются.

## Настройка задержки

На вкладке *Модель* есть пресет скорости (Быстро / Баланс / Плавно). Основная часть задержки - ожидание конца фразы: короче фразы - быстрее результат, но перевод более рваный. Модель побольше точнее, но не быстрее. В логе (`livedub.log`) печатается время каждого этапа (`[задержка] ...`), по нему видно, где уходит время.

## Сборка .exe (по желанию)

Запусти `build.bat`. Результат появится в `dist\LiveDub`. Эта сборка экспериментальная, надёжный способ запуска это `start.bat`.

## Ограничения

- Только Windows (WASAPI loopback, глобальные клавиши, трей).
- Пока озвучка играет в наушниках, распознавание на паузе, иначе программа услышит и переведёт собственный голос.
- Фразы режутся по паузам, поэтому очень быстрая речь переводится кусками. На вкладке **Модель** увеличь паузу и максимальную длину фразы для более цельных фраз, но задержка вырастет.
- Игры в настоящем полноэкранном режиме скрывают субтитры, используй режим «в окне без рамки».
- Комментарии в коде на русском (сам интерфейс на 4 языках, новые языки добавляются в `i18n.py`).

## Приватность и согласие

Звук обрабатывается локально. Распознанный **текст** отправляется в Google Translate (неофициальный веб-эндпоинт), запасной MyMemory и в синтез речи Microsoft Edge. Это неофициальные бесплатные сервисы: они могут измениться или перестать работать, и предназначены для личного использования. Если ты захватываешь чужой голос, предупреждай людей и соблюдай правила сервиса, которым пользуешься.
