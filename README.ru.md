# LiveDub

**Живой перевод и переозвучка речи для Windows.** LiveDub слушает всё, что играет на компьютере (звонок, стрим, видео на YouTube), распознаёт речь, переводит её и показывает субтитры поверх экрана. Перевод можно озвучивать голосом, а в обратную сторону программа умеет произносить *твои* слова в виртуальный микрофон, чтобы собеседник в звонке слышал тебя на своём языке.

## Возможности

- **Живые субтитры** поверх любых программ (игры в окне без рамки, браузеры, плееры). На экране остаются 3 последние фразы: новая крупная и яркая, старые мельче и тусклее, чтобы успеть дочитать.
- **Озвучка**: перевод речи собеседника звучит в твоих наушниках.
- **Голосовой режим**: зажимаешь клавишу, говоришь на своём языке, отпускаешь, и перевод звучит в виртуальный микрофон (Discord, Zoom, Teams, OBS, игры...). Пока клавиша зажата, твой настоящий голос не слышен собеседнику.
- **Живёт в трее**, спит, пока его не включишь, управляется с NumPad. Субтитры можно переносить между мониторами.
- **Распознавание речи локальное** (Whisper через `faster-whisper`, на видеокарте NVIDIA или процессоре). В онлайн-сервисы уходят только короткие куски *текста* для перевода и озвучки.
- Любой язык, который знает Whisper (около 99), или `auto`, чтобы переводить всё, кроме твоего языка.

## Как это работает

```
 Всё, что ты слышишь (WASAPI loopback)
          |
   поиск фраз по громкости (пауза 0.5 с / максимум 6 с)
          |
   faster-whisper (локально) -> проверка языка
          |
   перевод: Google (gtx) -> deep-translator -> MyMemory
          |
          +--> субтитры (Tkinter, поверх всех окон, история из 3 строк)
          +--> edge-tts -> твои наушники                (озвучка, по желанию)

 Твой микрофон --> LiveDub --> VB-Cable --> "микрофон" в Discord/Zoom/OBS
   зажал Num7/Num8: микрофон для собеседника заглушен, речь записывается
   -> Whisper (твой язык) -> перевод -> edge-tts -> VB-Cable
```

Весь код лежит в одном файле [`livedub.py`](livedub.py). Внутри работает несколько потоков, которые общаются через очереди:

| Поток / функция | Что делает |
|---|---|
| `capture_loop` / `record_session` | записывает звук системы, режет на фразы |
| `translate_loop` | Whisper, проверка языка, перевод |
| `dub_synth_loop`, `dub_play_loop` | готовит озвучку следующей фразы, пока играет предыдущая |
| `mic_loop` / `mic_session` | пересылает микрофон в виртуальный кабель, глушит его, пока держишь клавишу |
| `voice_out_loop` | твоя речь -> перевод -> голос в кабель |
| `hotkey_thread` | глобальные клавиши NumPad (`RegisterHotKey`), отслеживает отпускание клавиши |
| `main` | окно субтитров на Tkinter, значок в трее (`pystray`), очередь команд |

Tkinter трогает только главный поток: клавиши и трей кладут команды в очередь `cmd_q`, а главный поток их обрабатывает.

## Что нужно

- Windows 10/11
- Python 3.10+ (в установщике поставь галочку **Add Python to PATH**)
- Интернет (перевод и озвучка онлайн)
- По желанию: видеокарта NVIDIA для быстрого распознавания
- Для голосового режима: [VB-Cable](https://vb-audio.com/Cable/) (бесплатный виртуальный аудиокабель)

## Установка и запуск

```
git clone https://github.com/DazaiT/livedub.git
cd livedub
pip install -r requirements.txt
python livedub.py
```

При первом запуске скачивается модель Whisper (около 1,5 ГБ для `medium`) в папку `models` рядом со скриптом. Для запуска без чёрного окна используй `start.bat`.

Программа стартует «спящей». Нажми **Num1** (NumLock включён), чтобы включить субтитры.

### Настройки

Всё в начале `livedub.py`:

```python
SOURCE_LANG = "nl"     # язык собеседников ("auto" = любой, кроме твоего)
TARGET_LANG = "ru"     # твой язык: субтитры, озвучка и язык, на котором говоришь ты
PTT_LANGS = {"7": "nl", "8": "en"}   # зажал Num7 / Num8 -> на какой язык переводить твою речь
GPU_MODEL = "medium"   # "small" легче для видеокарты (меньше лагов в играх)
```

Голоса для разных языков лежат в `VOICES` (названия голосов Edge TTS).

### Видеокарта NVIDIA

Скрипт сначала пробует видеокарту, а если не выходит, сам переходит на процессор. Если пишет про недостающие библиотеки, выполни `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`.

### Настройка голосового режима (один раз)

1. Установи VB-Cable и перезагрузи компьютер.
2. В программе для звонков (Discord, Zoom...) выбери микрофоном **CABLE Output**.
3. Настоящий микрофон оставь микрофоном по умолчанию в Windows (или укажи `MIC_NAME`).
4. Зажми **Num7** или **Num8**, говори, отпусти.

Голосовой режим включается вместе с программой, потому что приложение для звонков теперь слушает виртуальный кабель. Num6 выключает его.

## Управление (NumLock включён)

| Клавиша | Действие |
|---|---|
| Num1 | субтитры вкл / выкл (сон) |
| Num2 | субтитры на следующий монитор |
| Num3 | показать / скрыть оригинал |
| Num4 / Num5 | текст мельче / крупнее |
| Num6 | голосовой режим вкл / выкл |
| Num7 / Num8 (зажать) | говоришь -> перевод на язык из `PTT_LANGS` |
| Num0 | озвучка собеседника вкл / выкл |
| Num. | повторить последнюю фразу голосом |
| Num9 | выход |

Пока программа запущена, голые клавиши NumPad принадлежат ей. Поставь `HOTKEY_MODIFIER = "ctrl"`, чтобы использовать Ctrl+Num. Субтитры можно перетаскивать мышью, правая кнопка очищает. То же самое есть в меню значка в трее.

## Сборка .exe (по желанию)

Запусти `build.bat`. Результат появится в `dist\LiveDub`. Эта сборка экспериментальная, надёжный способ запуска это `start.bat`.

## Ограничения

- Только Windows (WASAPI loopback, глобальные клавиши, трей).
- Пока озвучка играет в наушниках, распознавание на паузе, иначе программа услышит и переведёт собственный голос.
- Фразы режутся по паузам, поэтому очень быстрая речь переводится кусками. Увеличь `PAUSE_SECONDS` / `MAX_SECONDS` для более цельных фраз, но задержка вырастет.
- Игры в настоящем полноэкранном режиме скрывают субтитры, используй режим «в окне без рамки».
- Тексты интерфейса и комментарии в коде пока на русском.

## Приватность и согласие

Звук обрабатывается локально. Распознанный **текст** отправляется в Google Translate (неофициальный веб-эндпоинт), запасной MyMemory и в синтез речи Microsoft Edge. Это неофициальные бесплатные сервисы: они могут измениться или перестать работать, и предназначены для личного использования. Если ты захватываешь чужой голос, предупреждай людей и соблюдай правила сервиса, которым пользуешься.
